12

VS Code is powerful mostly because of extensions.

Tip For almost anything you want to do, there is probably already an extension that makes it easier.

You do not need all of these immediately, but these are the ones we commonly use.

Very helpful

GitHub Copilot

Useful for boilerplate and exploring ideas. Treat it like a helper, not something that writes everything for you.

Error Lens

Shows errors inline instead of just underlining them. Makes debugging much easier.

Data Wrangler

Lets you visually inspect and clean CSVs and tabular data. Very helpful if you are not fully comfortable with Pandas yet.

Rainbow CSV

Color-codes columns in CSV files so they are actually readable.

Material Icon Theme

Makes file and folder icons easier to distinguish. Small thing, but nice.

Language-specific, as needed

C/C++

Adds IntelliSense and basic debugging for C and C++.

Other languages

Whatever language you are using, there is almost always an extension for it. Just search it.

Optional

Gather by Microsoft

Useful for notebooks. Can extract the exact cells needed to run something and package them cleanly.

Git and SSH

VS Code already has built-in Git support, so you do not need an extension for that.

SSH keys are also something you set up once. See the SSH section for that. They let you:

  • Connect to GitHub without passwords
  • Connect to remote machines more easily
Tip Once SSH keys and Project Manager are set up, your workflow becomes much faster.

Final thought

Do not install everything at once.

Start with the core tools, then add things as you need them. VS Code is meant to grow with how you work.
