Section 03

Install Python

Python is the main language for this workflow. Before installing anything, the first move is to check whether your machine or remote system already has it.

Check Python Python downloads
03

We use Python for basically everything. It is simple, powerful, and works well with all the tools we use.

First: check if you already have it

Before installing anything, just check:

Terminal
python3 --version

If you see a version number, you are good. No need to reinstall.

Tip If you are working on a remote machine, you likely already have Python. If you are using the ICER cluster, then it is probably a module.

If you do not have Python

Installation can vary depending on your machine, so do not stress about memorizing commands.

The easiest options are:

  • Go to the official Python downloads page and install it normally.
  • Or search for install Python on [your system] and follow a walkthrough for your operating system.

Official Python downloads:

python.org/downloads

Mac optional install

On Mac, one common option is Homebrew:

Mac terminal
brew install python

Windows note

If you are on Windows, it is strongly recommended to use WSL, or Windows Subsystem for Linux.

Install WSL first, then install Python inside WSL. This gives you a much smoother setup.

That is it

Once python3 --version works, you are done.

VS Code will use this automatically for running code, notebooks, and everything else.
