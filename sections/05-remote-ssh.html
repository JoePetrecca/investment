Section 05

Remote SSH

Remote SSH lets you connect VS Code directly to machines like Moria, ICER, or any other SSH host. You edit from your laptop, but the code and files live on the remote machine.

Start setup Back to sections
05

A huge part of programming is running code on remote machines. These systems are much more powerful than your laptop, and VS Code makes connecting to them feel almost like working locally.

This setup only needs to be done once. After that, connecting becomes very quick.

Step-by-step setup

1. Open Remote Connection Menu

Click the small icon in the bottom left corner of VS Code. It looks like two arrows pointing.

2. Connect to a Host

Select Connect to Host...

3. Add a New Host

Click Add New SSH Host...

Tip If you do not see these options, VS Code will prompt you to install the Remote SSH extension.

4. Enter Your SSH Command

Type your SSH command. For example:

SSH command
ssh petrecc1@moria.egr.msu.edu

Your username and hostname will be different depending on the system you are connecting to.

5. Save to SSH Config

Select your SSH config file, which is usually the default option.

This step just saves your connection so you do not have to type it again.

6. Host Added

You will see a confirmation popup. You can close it.

Connecting every time after setup

From now on, connecting is much easier.

7. Open Remote Menu Again

Click the same bottom-left icon.

8. Connect to Host

Click Connect to Host...

9. Select Your Machine

Click your configured host, for example moria.

Warning If your host does not appear here, something went wrong earlier. Go back and redo the setup.

10. Accept the Fingerprint

Type yes when prompted.

11. Enter Your Password

Type your password for the remote machine.

12. Open a Folder

Once connected, click Open Folder and navigate to your working directory.

13. Trust the Workspace

Click Yes, I trust the authors and check the box to trust everything in that folder.

Tip Trusting the workspace avoids annoying restrictions and lets everything work properly.

What this actually does

You are now editing files directly on the remote machine while using VS Code locally. That means:

Code runs remotely

Your scripts run on the supercomputer or remote machine.

Files live remotely

Your project files stay on the remote system.

VS Code is the interface

Your local VS Code window becomes the editor for that machine.

Important note

This is the basic way to connect. Later, we will set up Project Manager, which lets you skip most of this and jump directly into your projects. That is absolutely worth doing.
