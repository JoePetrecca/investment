Section 01

Windows Subsystem for Linux

WSL lets Windows users run a real Linux environment directly inside Windows. This helps your tools, commands, and development workflow match what people use on Mac, Linux, and remote machines.

Start setup Back to sections
01

If you are using Windows, we recommend installing WSL, or Windows Subsystem for Linux. WSL allows you to run Linux commands and tools directly within Windows. It gives you the same kind of tools, commands, and behavior as everyone else using Mac or Linux, which makes everything much smoother.

Tip Using WSL avoids a lot of weird Windows-specific issues.

What is WSL?

WSL is basically a lightweight Linux system running on your machine. You can:

  • Use a normal terminal, such as bash
  • Install packages like you would on a server
  • Run Python, Git, and other tools cleanly

Install WSL

Open PowerShell and run:

PowerShell
wsl --install

That is it for most setups.

This will:

  • Install WSL
  • Install a Linux distribution, usually Ubuntu

Restart your computer if it asks.

First launch

After installing, open the Ubuntu app.

It will ask you to:

  • Create a username
  • Create a password

This is your Linux environment.

Update your system

Once inside WSL, run:

Ubuntu terminal
sudo apt update
sudo apt upgrade

Install Python inside WSL

Ubuntu terminal
sudo apt install python3 python3-pip

Then check:

Ubuntu terminal
python3 --version

Using WSL with VS Code

Install the Remote - WSL extension in VS Code.

Then:

  • Open VS Code
  • Connect to WSL
  • Work inside it like a normal environment
Tip From this point on, treat WSL like your main development environment, not Windows.

If you get stuck

This is a very common setup, so do not stress if something does not work immediately.

You can:

  • Look up quick guides or videos
  • Search the exact error message you see
  • Follow step-by-step walkthroughs online

There are tons of good resources for WSL, so almost any issue you hit has already been solved.
