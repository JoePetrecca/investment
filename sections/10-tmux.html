Section 10

tmux

tmux keeps terminal sessions alive after you disconnect. This is essential when running long scripts on remote machines like Moria.

Start section Back to sections
10

tmux stands for terminal multiplexer.

That sounds fancy, but the idea is simple: it lets you run terminal sessions that keep going even if you disconnect.

This is extremely useful on remote machines like Moria:

  • Start a long script
  • Disconnect or close your laptop
  • Come back later and it is still running
Tip If you are not using tmux on remote machines, you will eventually lose work.

Start a session

To start a new session:

Terminal
tmux new -s mysession

This creates a session named mysession.

Breakdown:

tmux

Run tmux.

new

Create a new session.

-s

Give the session a name.

Detach and leave it running

To leave the session but keep it running:

tmux shortcut
Ctrl + b, then d

This is not two keys at once:

  • Press Ctrl + b
  • Then press d

You will return to your normal terminal, but the session is still running in the background.

List sessions

To see what sessions exist:

Terminal
tmux ls

This shows all active sessions.

Tip If you are not sure whether something is still running, check tmux ls.

Reattach to a session

To go back into a session:

Terminal
tmux attach -t mysession

Breakdown:

attach

Reconnect to a session.

-t

Choose the target session.

mysession

The name of the session.

You will be exactly where you left off.

Kill a session

To fully exit and kill the session, just type this inside tmux:

Inside tmux
exit

Alternatively, you can kill it from outside:

Terminal
tmux kill-session -t mysession

Quick workflow

Typical usage:

Terminal
tmux new -s training
# run your script
Ctrl + b, then d
# later...
tmux attach -t training
The point

Start the job inside tmux, detach when you need to leave, and reattach later to check on it.
