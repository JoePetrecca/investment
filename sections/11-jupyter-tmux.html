Section 11

Jupyter Notebook Code in tmux

Notebooks are great for exploration, but long-running jobs are safer as Python scripts inside tmux. This keeps the code running even if you disconnect.

Start section Back to sections
11

Jupyter notebooks are great for exploration, but they are not necessarily ideal for long-running jobs on remote machines. If you close your laptop, lose connection, or disconnect from Moria, the notebook may stop running.

For long jobs, the safer workflow is:

1. Write and test

Use the notebook to explore and make sure the code works.

2. Export

Turn the notebook into a normal Python script.

3. Run in tmux

Run the script inside tmux so it survives disconnects.

This lets the code keep running even if you disconnect.

Export a notebook to a Python script

In VS Code, open the notebook you want to run.

Click the three dots at the top of the notebook.

Click Export.

Choose Python Script.

VS Code will create a .py version of the notebook. You may see a white dot on the file tab, which means the file has unsaved changes. Save the file before running it.

Run the script in tmux

This is detailed in the tmux section, but simplified here. Once the Python script is saved, start a tmux session:

Terminal
tmux new -s myjob
Warning Do not forget to activate your virtual environment when you go into tmux.

Then run the script:

Inside tmux
python your_script.py

To leave it running, detach from tmux:

tmux shortcut
Ctrl + b, then d

Later, reconnect with:

Terminal
tmux attach -t myjob
Tip If you are running something that may take a long time, run it as a .py script inside tmux, not directly as a notebook.

Optional: using Gather

Sometimes you do not want to run the entire notebook. You only want to run one important cell and the cells needed to make that cell work.

The Gather extension from Microsoft can help with this. It collects the selected cell and the cells that it depends on into a new notebook. Then you can export that smaller notebook to a Python script and run it in tmux.

The workflow is:

  1. Use Gather to collect the needed notebook cells
  2. Export the gathered notebook as a Python script
  3. Save the script
  4. Run it inside tmux

This is helpful when your original notebook has lots of exploratory cells that you do not want to rerun.

Note The extension does not work all of the time with complex code.
