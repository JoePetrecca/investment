Section 04

Miniforge and Micromamba

Environments keep projects separated. That means each project gets the Python version and packages it needs without breaking everything else.

Read section Miniforge install page
04

At some point, you are going to install packages and something will break. Different projects need different versions of Python or libraries, and mixing everything together causes problems fast.

This is why we use Miniforge or Micromamba.

What this is

Miniforge and Micromamba are lightweight versions of Conda. They let you create isolated environments so each project can have exactly what it needs without interfering with anything else.

That means:

  • One project can use Python 3.11
  • Another project can use a different setup
  • Nothing conflicts
Tip Think of environments as separate boxes for each project. Nothing leaks between them.

Why we suggest this

  • Avoids dependency conflicts
  • Easy to install packages like NumPy, Pandas, PyTorch, and more
  • Works well on remote machines and clusters
  • Much cleaner than installing everything globally

Micromamba in particular is:

  • Faster
  • Lighter
  • Simpler to manage

Which one should you use?

Either is fine.

Miniforge

More standard and familiar. This is a good default if you want something close to the normal Conda experience.

Micromamba

Faster and more lightweight. This is a good choice if you want a smaller, quicker environment manager.

Installation

Installation varies slightly depending on your system, so the easiest approach is:

  • Use the Miniforge GitHub page, which has curl and wget commands for Linux and Unix systems.
  • Search for install miniforge or install micromamba for your system.
  • Follow a guide or video.

Miniforge installation page:

github.com/conda-forge/miniforge

Basic idea

You do not need to memorize this. The typical workflow looks like this:

Mamba
mamba create -n myenv python=3.11
mamba activate myenv
mamba install numpy pandas

Or with Micromamba:

Micromamba
micromamba create -n myenv python=3.11
micromamba activate myenv
micromamba install numpy pandas
